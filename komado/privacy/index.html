プライバシーポリシー（Komado）

開発者: Toshihiro.nakao
制定日: 2026年10月31日

Toshihiro.nakao（以下「当方」といいます）は、iOS / iPadOS アプリ「Komado」（以下「本アプリ」といいます）における利用者の情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。本アプリは、お店の店主が予約を管理し、お客様向けの Web 予約ページを公開するためのアプリです。お客様が予約ページで入力した情報の取り扱いは、予約ページのプライバシーポリシーで別に定めています。

1. 基本方針

  • 予約・お客様の情報・店舗の設定は、利用者の端末と、利用者自身の iCloud に保存します。当方はこれらを読むことができません。
  • 予約ページに載せるために利用者が入力した店舗の情報（店舗名・電話番号・メニュー・空いている時間など）は、予約ページに表示するために公開します（「2. 本アプリで扱う情報」）。
  • 予約ページから届く予約の内容は、利用者の端末にしかない鍵で暗号化された状態で届き、当方は中身を読むことができません。
  • 会員登録はありません。
  • 広告、利用状況の解析、トラッキング、外部の SDK は使っていません。

2. 本アプリで扱う情報

利用者が入力・保存する情報

店舗の情報（店舗名・電話番号・営業時間・休日・メニューと料金・予約の受け方の設定）、予約（日時・メニュー・料金・状態・メモ）、お客様の情報（お名前・ふりがな・電話番号・メールアドレス・カルテのメモ・気をつけること・来店の履歴）です。

お客様の個人情報について

本アプリには、利用者のお店のお客様の個人情報を入力・保存できます。これらは利用者の端末と利用者自身の iCloud にだけ保存され、当方には送られません。お客様の個人情報の取り扱いについては、お店（利用者）が責任を持って管理してください。

予約ページに公開する情報

予約ページを表示するために、次の情報を Apple の CloudKit の公開データベースに保存します。予約ページの URL を知っている人は、これらを見ることができます。

  • 店舗名、電話番号、メニューと料金、予約ページに載せる文章（メッセージ・行き方・注意事項・SNS のリンクなど、利用者が入力したもの）
  • 空いている時間（予約が入っている時間を除いたもの。予約したお客様の情報は含みません）
  • 予約の受け方の設定、プランの有効期限、予約の暗号化に使う公開鍵

Web から届いた予約については、お客様が予約状況を確かめるための記録（予約の状態・日時・メニュー名）も保存します。この記録にお客様のお名前や連絡先は含まず、予約日から 90 日を過ぎると本アプリが削除します。

予約ページから届く予約

お客様が予約ページで入力した内容は、利用者の端末にしかない鍵で暗号化されて届き、本アプリが端末の中で読み取ります。受け取りが終わると、暗号化された元のデータは予約サーバーから削除されます（受け取られなかったものも 60 日で削除されます）。

3. データの保存場所

  • 予約・お客様の情報・店舗の設定は、端末の中と、利用者自身の iCloud のプライベートな領域に保存し、同じ Apple ID の端末どうしで同期します。当方はこの領域にアクセスできません。
  • 予約を読むための鍵は、iCloud キーチェーンに保存し、同じ Apple ID の端末どうしで同期します。
  • ホーム画面とロック画面のウィジェットに表示するため、次のお客様や返事待ちの件数などの要約を、端末の中のアプリ専用の領域に保存します。
  • 本アプリを削除すると、端末の中のデータは削除されます。iCloud に保存されたデータは、同じ Apple ID の別の端末や、再インストールした本アプリで引き続き使えます。

4. 端末の機能へのアクセス

  • 通知：予約ページから新しい予約が届いたことをお知らせするために使います。許可しなくても、本アプリを開くと届いた予約が取り込まれます。
  • 写真への追加：予約ページの QR コードを写真に保存するときだけ使います。写真の読み取りは行いません。許可しなくても、QR コードの共有や URL のコピーはできます。

5. 外部サービス

Apple の iCloud（CloudKit）

データの保存と同期、予約ページに公開する情報の保存、新しい予約の通知に使います。Apple のプライバシーポリシーは https://www.apple.com/jp/legal/privacy/ をご覧ください。

予約サーバー（Cloudflare）

当方が運営する予約サーバーは、Cloudflare, Inc. のサービスの上で動いています。本アプリは、予約の受け取りの完了、予約の取り消しや日時の変更に伴う予約枠の解放、新しい版の有無の確認のために、予約サーバーと通信します。送るのは店舗の予約ページの URL、予約の日時と予約枠の情報、店舗の鍵による署名で、お客様のお名前や連絡先は送りません。通信の際には、Cloudflare がサービスの提供のために IP アドレスなどを処理します。Cloudflare のプライバシーポリシーは https://www.cloudflare.com/privacypolicy/ をご覧ください。

6. アプリ内課金

本アプリのプラン（自動更新のサブスクリプション）の購入は、Apple の App Store で処理されます。当方はクレジットカードなどの支払い情報を受け取りません。プランの状態は Apple から本アプリに伝えられ、予約ページで予約を受け付けるかどうかの判断に使います。

7. 第三者への提供

当方は、利用者の情報を第三者に提供しません。ただし、法令に基づく場合を除きます。外部サービスの利用については「5. 外部サービス」をご覧ください。

8. データの削除

  • 予約やお客様の情報は、本アプリの中でいつでも削除できます。
  • 店舗を削除すると、その店舗の予約・メニュー・営業時間・休日・予約ページの公開情報・鍵を削除します。
  • 「すべてのデータを消して初期化」を行うと、本アプリのすべてのデータを、iCloud に保存されたものも含めて削除します。
  • iCloud に保存されたデータは、端末の「設定」の iCloud の管理画面からも削除できます。

9. 子どもの利用

本アプリは、お店の運営に使うためのアプリで、13 歳未満の子どもを対象としていません。

10. 本ポリシーの変更

当方は、必要に応じて本ポリシーを変更することがあります。変更後のポリシーは、このページに掲載した時点から効力を生じます。

11. お問い合わせの際に受け取る情報

サポートページのお問い合わせフォームは、Google LLC の Google フォームで受け付けています。お問い合わせの際に入力された情報（お名前、返信先のメールアドレス、お問い合わせの内容など）は、お問い合わせへの回答と、不具合の調査・改善のためだけに使い、法令に基づく場合を除いて第三者に提供しません。対応が終わり必要がなくなった情報は削除します。フォームでの取り扱いには、Google のプライバシーポリシーも適用されます。本アプリを使うことで、これらの情報が当方へ送られることはありません。

12. お問い合わせ

本ポリシーまたは本アプリのプライバシーに関するお問い合わせは、サポートページまでご連絡ください。
